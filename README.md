# LinkDock — Personal Web Launchpad & Bookmark Organizer

หน้าแดชบอร์ดรวมทางลัดเข้าเว็บไซต์ส่วนตัว (Personal Startpage / Bookmark Manager) ที่ออกแบบมาให้ตั้งชื่อลิงก์เองได้ จัดหมวดหมู่ได้ ปักหมุดทางลัดที่ใช้บ่อยไว้ด้านบน (Speed Dial) และลากสลับตำแหน่งได้ตามต้องการ ทำงานแบบ Static Web 100% จึงนำไปอัปโหลดขึ้น **GitHub Pages** ได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน

## ฟีเจอร์หลัก (Features)

- **ตั้งชื่อและจัดหมวดหมู่ได้อย่างอิสระ**: เพิ่ม แก้ไข ลบทางลัด พร้อมตั้งชื่อที่เข้าใจง่าย ใส่บันทึกช่วยจำ และเลือกสีประจำหมวดหมู่ได้
- **ดึงไอคอนเว็บอัตโนมัติ (Auto Favicon)**: เพียงวาง URL เว็บไซต์ไหนก็ได้ ระบบจะดึงและแสดงไอคอนของเว็บไซต์นั้นให้อัตโนมัติทันที (ทั้งขณะวาง URL และบนการ์ดทางลัด)
- **Speed Dial (ทางลัดติดดาว)**: ปักหมุดเว็บที่เข้าทุกวันไว้แถบบนสุด พร้อมคีย์ลัดกด `Alt + 1..9` เพื่อเปิดเว็บทันที
- **Drag & Drop จัดระเบียบง่าย**: ลากการ์ดเพื่อสลับลำดับ หรือลากข้ามหมวดหมู่ได้ทันที
- **Omni-Search Bar**: พิมพ์ค้นหาบุ๊กมาร์กแบบ Real-time หรือสลับโหมดเพื่อค้นหาบน Google, YouTube, GitHub ได้ในช่องเดียว
- **Grid & Compact View**: ปรับสลับมุมมองระหว่างการ์ดมาตรฐานและแบบกะทัดรัดได้ตามต้องการ บนดีไซน์โทนสว่างสะอาดตา (Light Theme)
- **Export / Import JSON**: สำรองข้อมูลออกจาก `localStorage` เป็นไฟล์ `.json` เพื่อย้ายเครื่องหรือเก็บแบ็กอัปได้ตลอดเวลา

## วิธีนำไปขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (เช่น `LinkDock`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `style.css`, `app.js`, `README.md`) ขึ้นไปยัง Branch `main`
3. ไปที่เมนู **Settings** > **Pages** ของ Repository
4. ที่หัวข้อ **Build and deployment** เลือก Source เป็น `Deploy from a branch` และเลือก Branch `main` (`/root`) แล้วกด **Save**
5. รอประมาณ 1 นาที จะได้ลิงก์ `https://<username>.github.io/LinkDock/` สำหรับตั้งเป็นหน้าแรกของเบราว์เซอร์ได้ทันที!
